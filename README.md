# Applied-AI-Projects
A collection of practical AI projects showcasing Retrieval-Augmented Generation (RAG), Multi-Agent Systems, MCP servers, LLM-powered applications, and intelligent automation built using Python, LangChain, OpenAI, ChromaDB, and AutoGen.

## Projects

### Medical RAG Chatbot
- Built a medical question-answering system using LangChain, ChromaDB, and OpenAI.
- Processes PDF documents and provides context-aware answers.

### Research Paper RAG Assistant
- End-to-end RAG pipeline for querying research papers.
- Uses semantic search and vector databases for knowledge retrieval.

### Weather MCP Server
- Custom MCP server providing real-time weather information.
- Demonstrates tool integration using Model Context Protocol.

### AI Car Racing Multi-Agent Simulator
- Multi-agent system built using AutoGen.
- Simulates collaboration between Game Developer and Tester agents.
